# Mathematics, Understood

**A comprehensive self-study mathematics series—from foundational numeracy to advanced mathematics—with connected science applications.**

> From intuition to symbols. From symbols to understanding. From understanding to discovery.

## Non-negotiable learning commitments

1. For suitable lessons, use **problem statement → first attempt → intuition → representations → formal mathematics → comparison and consolidation → guided practice → independent transfer**. Use a different order when prerequisites, task complexity, or the learner's needs make it more appropriate, and document why.
2. Teach the **construction** of equations and models, not only interpretation or formula use.
3. Teach readers to formulate conjectures, reason, build and check proofs, find counterexamples, and generalize results—not only follow worked proofs.
4. Use diagrams, graphs, tables, geometric constructions, and other visuals where they meaningfully teach the content.
5. Also develop visual independence through embedded prompts to predict, sketch, complete, reconstruct, describe, and transfer representations. Do not assume all learners experience vivid mental imagery.
6. Treat mathematical correctness, explicit assumptions, traceable claims, independent checks, accessible self-study, and learner testing as release requirements.
7. Engagement and aesthetics must serve learning; they never outrank scientific or mathematical rigor.

## Working rule

A draft is not verified merely because it sounds plausible or because an LLM has reviewed it twice. Record the claim, assumptions, derivation/source, checking methods, status, limitations, and reviewer. Unresolved high-severity errors block release.
