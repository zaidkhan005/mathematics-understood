# Mathematical checks

Choose tests according to the mathematics involved: independent hand derivation, substitution and boundary cases, algebra system checks (within stated assumptions), numerical sampling as an error detector (not a proof), dimensional analysis, code-based tests, proof assistant formalization, and qualified human review. Document what each check can and cannot establish.

For proofs, check hypotheses, definitions, quantifiers, logical implications, hidden assumptions, edge cases, and whether the proof establishes the exact claim rather than a nearby one.
