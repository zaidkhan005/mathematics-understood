# Verification system

A correct-looking explanation is not evidence of correctness. Track significant claims and their assumptions; select checking methods suited to claim type; preserve exact sources and reproducible checks; and record unresolved issues. High-severity defects block release.

Use separate but linked records for: claims, sources, mathematical/computational checks, peer reviews, visual checks, and learner pilots. LLM review can find potential errors but should not be treated as independent confirmation when it repeats the same reasoning.
